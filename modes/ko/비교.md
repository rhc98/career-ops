# 모드: 비교 -- 복수 채용공고 비교

10개 차원의 가중 스코어링 매트릭스:

| 차원 | 가중치 | 기준 1-5 |
|------|--------|----------|
| North Star 정합성 | 25% | 5=정확한 타겟 역할, 1=관련 없음 |
| CV 매칭 | 15% | 5=90%+ 매칭, 1=40% 미만 |
| 레벨 (시니어+) | 15% | 5=Staff+, 4=시니어, 3=미드시니어, 2=미드, 1=주니어 |
| 예상 보상 | 10% | 5=상위 분위, 1=시장 이하 |
| 성장 궤적 | 10% | 5=다음 레벨로의 명확한 경로, 1=성장 한계 |
| 원격 품질 | 5% | 5=풀 리모트 비동기, 1=출근 전용 |
| 기업 평판 | 5% | 5=최우수 고용주, 1=레드플래그 |
| 기술 스택 현대성 | 5% | 5=최신 AI/ML, 1=레거시 |
| 오퍼까지 속도 | 5% | 5=빠른 프로세스, 1=6개월 이상 |
| 문화 시그널 | 5% | 5=빌더 문화, 1=관료적 |

**한국 시장 추가 고려사항:**
- 기업 유형 (대기업/스타트업/외국계)에 따른 안정성 vs 성장성 트레이드오프
- 연봉 구조 차이 (기본급 비중, 성과급, 스톡옵션)
- 복리후생 실질 가치 (4대보험 외 추가 복지)

각 채용공고: 차원별 점수, 가중 총점 산출.
최종 랭킹 + time-to-offer를 고려한 추천.

사용자에게 채용공고가 없으면 요청. 텍스트, URL, 또는 트래커에서 이미 평가한 채용공고 참조 가능.
