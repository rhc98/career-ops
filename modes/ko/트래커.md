# 모드: 트래커 -- 지원 현황 조회

`data/applications.md`를 읽고 표시한다.

**트래커 포맷:**
```markdown
| # | Date | Company | Role | Score | Status | PDF | Report |
```

상태 흐름: `Evaluated` -> `Applied` -> `Responded` -> `Interview` -> `Offer` / `Rejected` / `Discarded` / `SKIP`

- `Evaluated` = 평가 완료, 지원 결정 대기 중
- `Applied` = 지원서 제출 완료
- `Responded` = 회사가 먼저 연락, 후보자가 응답 (인바운드)
- `Interview` = 면접 진행 중
- `Offer` = 오퍼 수령
- `Rejected` = 회사가 거절
- `Discarded` = 후보자가 제외하거나 공고 마감
- `SKIP` = 맞지 않음, 지원 안 함

사용자가 상태 업데이트를 요청하면 해당 행을 편집한다.

**통계도 함께 표시:**
- 총 지원 건수
- 상태별 분포
- 평균 Score
- PDF 생성률 (%)
- 리포트 생성률 (%)

**한국어 상태 참조:**
한국어로 상태를 입력해도 인식 (예: "평가됨", "지원함", "면접", "합격", "불합격"). `templates/states.yml`의 alias를 참조.
