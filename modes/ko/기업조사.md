# 모드: 기업조사 -- 심층 리서치 프롬프트

6개 축으로 구조화된 리서치 프롬프트 생성:

```
## 심층 조사: [회사명] -- [역할]

맥락: [회사]의 [역할]에 지원을 검토 중입니다. 면접에 필요한 실행 가능한 정보가 필요합니다.

### 1. AI 전략
- 어떤 제품/기능에서 AI/ML을 사용하는가?
- AI 스택은? (모델, 인프라, 도구)
- 테크 블로그가 있는가? 무엇을 발행하는가?
- AI 관련 논문이나 컨퍼런스 발표가 있는가?

### 2. 최근 동향 (최근 6개월)
- AI/ML/제품 분야 주요 채용?
- 인수합병이나 파트너십?
- 신제품 출시나 피봇?
- 투자 유치나 리더십 변동?

### 3. 엔지니어링 문화
- 배포 주기는? (CI/CD 방식)
- 모노레포인가 멀티레포인가?
- 주요 언어/프레임워크는?
- 리모트 우선인가 오피스 우선인가?
- 잡플래닛/블라인드에서의 엔지니어링 문화 리뷰?

### 4. 예상되는 도전과제
- 스케일링 관련 문제가 있는가?
- 안정성, 비용, 레이턴시 관련 과제?
- 인프라/모델/플랫폼 마이그레이션 진행 중?
- 리뷰에서 언급되는 페인 포인트?

### 5. 경쟁사 및 차별화
- 주요 경쟁사는?
- Moat/차별화 요소는?
- 경쟁사 대비 포지셔닝은?

### 6. 후보자 앵글
cv.md와 profile.yml의 구체적 경험을 기반으로:
- 이 팀에 어떤 고유한 가치를 제공하는가?
- 어떤 프로젝트가 가장 관련성이 높은가?
- 면접에서 어떤 스토리를 해야 하는가?
```

**한국 기업 특화 조사 항목:**
- **DART 공시** (dart.fss.or.kr): 상장사 재무, 평균 급여, 직원 수 추이
- **잡플래닛** (jobplanet.co.kr): 기업 리뷰, 면접 후기, 연봉 정보
- **블라인드** (teamblind.com): 내부자 리뷰, 팀 문화, 실제 워라밸
- **네이버 증권**: 재무 현황, 주가 추이 (상장사)
- **크런치베이스/로켓펀치**: 스타트업 투자 단계, 투자자 정보
- **뉴스 검색**: 최근 구조조정, 인수합병, 사업 확장 뉴스

각 섹션을 평가한 채용공고의 구체적 맥락으로 개인화.
