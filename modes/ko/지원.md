# 모드: 지원 -- 지원 보조 + 자기소개서 생성

후보자가 지원서를 작성할 때 사용하는 인터랙티브 모드. 화면에 보이는 폼을 읽고, 채용공고 컨텍스트를 로드하여 각 질문에 맞춤 답변을 생성한다. 한국 채용시장 고유의 자기소개서 작성 기능을 포함한다.

## 요구사항

- **Playwright 사용 시 (최적)**: 후보자가 브라우저를 보면서 Claude가 페이지와 상호작용 가능
- **Playwright 없이**: 후보자가 스크린샷을 공유하거나 질문을 직접 붙여넣기

## 워크플로우

```
1. 감지    -> Chrome 활성 탭 읽기 (스크린샷/URL/제목)
2. 식별    -> 페이지에서 회사 + 역할 추출
3. 검색    -> reports/에서 기존 리포트 매칭
4. 로드    -> 전체 리포트 + Section G (있으면) 읽기
5. 비교    -> 화면의 역할과 평가한 역할이 일치하는지 확인. 변경 시 알림
6. 분석    -> 보이는 모든 폼 질문 식별
7. 생성    -> 각 질문에 맞춤 답변 생성
8. 표시    -> 복사-붙여넣기 가능한 포맷으로 답변 제공
```

## 1단계 -- 채용공고 감지

**Playwright 사용 시:** 활성 페이지의 스냅샷 촬영. 제목, URL, 보이는 콘텐츠 읽기.

**Playwright 없이:** 후보자에게 요청:
- 폼의 스크린샷 공유 (Read 도구로 이미지 읽기 가능)
- 또는 폼의 질문을 텍스트로 붙여넣기
- 또는 회사 + 역할명을 알려주면 검색

## 2단계 -- 컨텍스트 식별 및 검색

1. 페이지에서 회사명과 역할 제목 추출
2. `reports/`에서 회사명으로 검색 (Grep, 대소문자 무관)
3. 매칭되면 -> 전체 리포트 로드
4. Section G가 있으면 -> 기존 답변 초안을 기반으로 활용
5. 매칭 없으면 -> 알리고 빠른 auto-pipeline 실행 제안

## 3단계 -- 역할 변경 감지

화면의 역할이 평가한 것과 다르면:
- **후보자에게 알림**: "역할이 [X]에서 [Y]로 변경되었습니다. 재평가할까요, 아니면 새 제목에 맞게 답변을 조정할까요?"
- **조정 시**: 재평가 없이 새 역할에 맞게 답변 조정
- **재평가 시**: A-F 전체 평가 실행, 리포트 업데이트, Section G 재생성
- **트래커 업데이트**: 필요 시 applications.md의 역할 제목 변경

## 4단계 -- 폼 질문 분석

보이는 모든 질문 식별:
- 자유 텍스트 (자기소개서, 지원동기, why this role 등)
- 드롭다운 (경력 연수, 어떻게 알게 되었는지, 비자 등)
- 예/아니오 (출근 가능, 비자 보유, 해외 이동 가능 등)
- 연봉 필드 (희망 연봉, 현재 연봉)
- 파일 업로드 (이력서, 자기소개서 PDF, 포트폴리오)

각 질문 분류:
- **Section G에 이미 답변 있음** -> 기존 답변을 다듬어 활용
- **새 질문** -> 리포트 + cv.md에서 답변 생성

## 5단계 -- 답변 생성

각 질문에 대해:

1. **리포트 컨텍스트**: 블록 B의 proof point, 블록 F의 STAR 스토리 활용
2. **기존 Section G**: 있으면 기반으로 다듬기
3. **톤 "내가 선택합니다"**: 지원자가 능동적으로 이 회사를 선택한 이유를 보여주는 프레이밍
4. **구체성**: 화면에 보이는 JD의 구체적 내용 참조
5. **career-ops proof point**: "Additional info" 필드가 있으면 포함

**한국어 폼 특화:**
- **희망 연봉 필드**: profile.yml의 범위를 참조하되, "협의 가능"으로 유연하게
- **현재 연봉 필드**: 가능하면 비워두거나 "개인 정보"로 표시 권장. 후보자에게 확인
- **경력 연수**: cv.md에서 자동 계산
- **어떻게 알게 되었는지**: 실제 경로를 정직하게 (Wanted, LinkedIn, 지인 추천 등)

**출력 포맷:**

```
## 답변: [회사명] -- [역할]

기반: Report #NNN | Score: X.X/5 | 아키타입: [유형]

---

### 1. [폼의 정확한 질문]
> [복사-붙여넣기 가능한 답변]

### 2. [다음 질문]
> [답변]

...

---

참고:
- [역할, 변경사항 등에 대한 관찰]
- [후보자가 검토해야 할 개인화 제안]
```

## 6단계 -- 지원 후 (선택)

후보자가 지원을 제출했다고 확인하면:
1. `applications.md`의 상태를 "Evaluated"에서 "Applied"로 업데이트
2. 리포트의 Section G를 최종 답변으로 업데이트
3. 다음 단계 제안: `/career-ops 연락` (LinkedIn 아웃리치)

## 스크롤 처리

폼에 보이는 것보다 더 많은 질문이 있으면:
- 후보자에게 스크롤해서 다른 스크린샷을 공유하도록 요청
- 또는 나머지 질문을 텍스트로 붙여넣기
- 전체 폼을 커버할 때까지 반복 처리

# 자기소개서 생성 (한국 시장 전용)

한국 채용시장에서 이력서와 함께 요구되는 핵심 서류. 서양의 Cover Letter와는 구조와 목적이 다르다.

## 자기소개서란?

자기소개서(자소서)는 후보자의 동기, 역량, 적합성을 서술형으로 전달하는 문서. 대기업은 정해진 항목(성장과정, 지원동기, 입사 후 포부 등)을 요구하고, 스타트업은 자유 형식이 많다.

## 자기소개서 워크플로우

```
1. 유형 판별 -> 정형(항목별) vs 자유형식
2. 요구사항 추출 -> 채용공고에서 핵심 역량/인재상 파악
3. 소재 수집 -> cv.md + article-digest.md에서 매칭 경험
4. 구조 설계 -> 회사/역할에 맞는 구조 선택
5. 초안 작성 -> 구체적 경험 + 지표 기반
6. 톤 조정 -> 기업 유형에 맞는 문체
7. 글자수 맞춤 -> 제한이 있으면 핵심만 압축
```

## 자기소개서 구조

### 유형 1: 정형 (대기업/중견기업 주로 사용)

**항목 1 -- 성장과정 / 자기소개**
- 본인의 전문성이 형성된 배경
- 관련 학습/경험의 연결 고리
- 길이: 보통 500-1000자

**항목 2 -- 지원동기**
- 왜 이 회사인지 (구체적 -- 제품, 기술, 미션 언급)
- 왜 이 역할인지 (JD의 핵심 요구사항과 본인 경험 연결)
- 길이: 보통 500-1000자

**항목 3 -- 직무 역량 / 관련 경험**
- 가장 관련성 높은 프로젝트/경험 1-2개
- STAR 구조로 구체적 수치 포함
- 길이: 보통 500-1000자

**항목 4 -- 입사 후 포부**
- 단기 (1년): 구체적 기여 계획
- 중장기 (3-5년): 성장 방향과 팀/회사에 대한 기여
- 길이: 보통 300-500자

### 유형 2: 자유형식 (스타트업/외국계 주로 사용)

- 핵심 역량 중심으로 3-4개 문단
- 구체적 프로젝트와 성과 위주
- 지원 동기를 자연스럽게 녹여내기
- 전체 길이: 800-1500자

## 톤 가이드

| 기업 유형 | 톤 | 특징 |
|-----------|-----|------|
| 대기업 | 격식체 (~습니다) | 체계적, 조직 내 역할 강조, 안정감 |
| 중견기업 | 격식체 | 성장 의지, 기여도 강조 |
| 스타트업 | 자연스러운 존댓말 (~해요/~합니다) | 주도성, 빠른 적응, 문제 해결 |
| 외국계 | 프로페셔널 존댓말 | 글로벌 경험, 커뮤니케이션, 자기주도 |

## 작성 규칙

### 절대 하지 않는 것
- 거짓 경험이나 지표 만들어내기
- "열정", "최선을 다하겠습니다" 같은 빈말
- cv.md에 없는 경험 언급
- 검색해서 나온 회사 슬로건만 복붙하기
- 모든 항목을 비슷한 구조로 반복

### 항상 하는 것
- cv.md + article-digest.md의 실제 경험과 수치 사용
- 채용공고의 자격요건/우대사항과 직접 연결
- 구체적 프로젝트명, 기술, 성과 수치 포함
- 회사의 실제 제품/서비스/기술 스택 언급 (WebSearch로 확인)
- 각 항목이 서로 다른 역량/경험을 보여주도록 구성

## 글자수 제한 대응

| 제한 | 전략 |
|------|------|
| 500자 이내 | 핵심 경험 1개 + 지원동기 1문장 + 포부 1문장 |
| 1000자 이내 | 경험 1-2개 + 지원동기 + 간단한 포부 |
| 1500자 이내 | 풀 구조 (성장과정/지원동기/역량/포부) 가능 |
| 제한 없음 | 1500자 내외 권장. 길다고 좋은 게 아님 |

## 출력 포맷

```
## 자기소개서: [회사명] -- [역할]

기반: Report #NNN | Score: X.X/5 | 아키타입: [유형]
글자수: [현재 글자수] / [제한]

---

### [항목 1 제목]
[본문]

### [항목 2 제목]
[본문]

...

---

참고:
- 글자수: [현재] / [제한] ([초과/여유] [N]자)
- [톤/내용 관련 후보자 검토 사항]
- [사실 확인이 필요한 항목]
```
